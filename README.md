
# AuthMaster

Central Authentication System.

## Architecture

- Frontend: GitHub Pages
- API Proxy: Vercel
- Backend: Google Apps Script
- Database: Google Sheets

## Features

- Register
- Login
- Logout
- Forgot Password
- OTP Verification
- Reset Password
- Change Password
- Session Validation

## Environment Variables

GAS_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
